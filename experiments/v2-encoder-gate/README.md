# v2 encoder 게이트 — 구조 임베딩, 사전 고정 기준 앞에서 멈추다

> surrogate v2 재설계의 첫 실행 사이클입니다. 회로의 *구조*만 보고 배우는 frozen encoder(고정
> 인코더)를 사람이 사전학습하고, 미리 정해 둔 3중 채택 게이트로 판정했습니다. 결과는 2회 연속
> **기각** — 임베딩만으로는 기존 표형식 feature를 이기지 못했고, Operator는 이를 정직한
> negative result(부정 결과)로 기록하고 사이클을 종결했습니다.

## 실험 전제

gen-002~008의 7세대 자율 진화가 남긴 가장 견고한 발견은 "학습 중 지표(val_mae)가 좋아져도
교차설계 일반화(처음 보는 설계에 대한 예측력)는 나아지지 않는다"였습니다. v2 spec은 그 벽을
넘기 위한 질적 전환으로 **표현(representation) 재설계**를 택했습니다: 회로 netlist(합성 결과로
나온 게이트 연결망)를 그래프로 바꾸고, self-supervised graph autoencoder(정답 라벨 없이 입력
일부를 가리고 복원하며 배우는 신경망)를 사전학습해, 그 임베딩(각 endpoint를 요약한 32개 숫자
벡터)을 기존 8개 표형식 feature 옆에 병기하는 계획입니다.

단, encoder를 루프에 투입하려면 spec §6에 **학습 전에 커밋해 둔** 채택 게이트 3개를 모두
통과해야 합니다. 결과를 보고 기준을 고치는 일(사후 튜닝)을 막기 위한 장치입니다.

## 방법

- **코퍼스**: ORFS 동봉 sky130 설계 7개(gcd·aes·chameleon·ibex·jpeg·microwatt·riscv32i)를
  digest 고정 docker 이미지로 합성만 수행해 netlist 그래프 코퍼스를 만들었습니다(총 18,804
  endpoints, 제외 0건). 이 중 riscv32i·chameleon 2개는 검증 전용(encoder-val)으로 분리했습니다.
- **사전학습**: 마스킹-재구성 방식 graph autoencoder를 2회 학습했습니다.
  - 1차: full-batch(전체 데이터의 기울기를 모아 epoch당 1회만 갱신) — 28 epoch에서 조기 종료.
    총 28번의 갱신은 명백한 과소학습이었습니다.
  - 2차: mini-batch(64개 그래프마다 갱신)로 학습 루프를 수정(Operator 승인) — 갱신 횟수가
    수천 번으로 늘었습니다.
- **채택 게이트(사전 고정, spec §6)**: ① 재구성 — 검증 loss가 naive 상수 예측보다 좋을 것,
  ② 붕괴 진단 — 임베딩이 전부 같은 벡터로 뭉개지지 않았을 것, ③ 선형 probe — "임베딩만으로
  선형회귀" 오차가 "표형식만으로 선형회귀" 오차 이하일 것.

## 결과

| 게이트 | 기준 | 1차(full-batch) | 2차(mini-batch) |
|---|---|---|---|
| 재구성 | val loss < naive 4.875 | 2.550 ✅ | 2.027 ✅ |
| 붕괴 진단 | 차원 std 중앙값 > 1e-6, 평균 cosine < 0.99 | 0.113 / 0.984 ✅ | 0.439 / 0.863 ✅ |
| 선형 probe | 임베딩만 ≤ 표형식만 (MAE 0.418) | **1.229 ❌** | **1.157 ❌** |
| 판정 | 3개 전부 통과 시 채택 | **기각** | **기각** |

부수 성과로, 라벨 4설계의 endpoint 이름 매칭(coverage)은 출력 포트를 비트 단위로 다루는
수정 후 gcd·aes·jpeg 1.000, ibex 0.9995로 0.95 게이트를 전부 통과했습니다 — 재현성 파이프라인
자체는 건강하다는 뜻입니다.

## 분석

핵심은 하나입니다: **구조만 담은 임베딩은, 라벨과 거의 직결된 타이밍 수치를 이미 가진 표형식
feature를 선형 비교에서 이길 수 없었습니다.** 라벨(배선 후 slack)은 대략 "합성 시점 slack +
드리프트"인데, 표형식 8개에는 그 합성 slack이 그대로 들어 있습니다. 반면 v2 spec은 임베딩을
구조 신호 전담으로 설계(타이밍 통계 제외)했으므로, 임베딩 단독 선형회귀가 0.418이라는 기준을
넘기는 처음부터 매우 어려운 과제였습니다.

그래서 이 기각은 시스템 고장이 아니라 게이트의 정상 작동입니다. 사전 고정 기준이 "약한 표현이
루프에 들어가 세대 예산을 소모하는 것"을 학습 2회 만에 차단했고, 그 근거(loss 곡선·진단 수치·
probe 결과)는 `models/encoder-v1.report.json`에 전부 남아 사후 검사가 가능합니다. 1차 기각의
원인 진단(28-step 과소학습)이 mini-batch 수정으로 이어진 것도 기록할 가치가 있는 학습입니다 —
개선은 있었지만(1.229→1.157) 구조적 한계를 뒤집기에는 부족했습니다.

단독을 *개선*하는가"(ablation형 — 한계 효용을 묻는 질문)로 바꾸는 것이지만, 기준 변경은
사후 튜닝이 아니라 **새 spec의 brainstorming → Codex 게이트를 거친 사전 고정**으로만
가능합니다. 관련 커밋: `9dfacd4`(1차 기각) · `dafa216`(mini-batch 수정) · `7d084af`(2차 기각).

## 용어

- **frozen encoder(고정 인코더)**: 사람이 1회 학습한 뒤 가중치를 고정(SHA 앵커)한 신경망.
  루프의 에이전트는 이를 변경할 수 없어 세대 간 공정 비교가 유지됩니다.
- **self-supervised(자기지도) 학습**: 정답 라벨 없이, 입력 일부를 가리고 복원하는 식으로
  데이터 자체에서 학습 신호를 만드는 방식.
- **임베딩(embedding)**: 복잡한 대상(여기서는 endpoint 주변 회로 구조)을 고정 길이 숫자
  벡터로 요약한 것.
- **선형 probe**: 표현의 품질을 재는 표준 기법. 표현 위에 가장 단순한 모델(선형회귀)만 얹어
  성능을 비교하면, 표현 자체에 담긴 정보량을 공정하게 잴 수 있습니다.
- **naive 상수 baseline**: 아무 학습 없이 평균값으로만 예측했을 때의 성능. 이보다 못하면
  학습이 아무것도 배우지 못했다는 뜻입니다.
- **negative result(부정 결과)**: 가설이 기각된 결과를 숨기지 않고 그대로 기록한 것. 이
  프로젝트에서는 "게이트가 무엇을 걸러냈는가"가 성과의 일부입니다.
