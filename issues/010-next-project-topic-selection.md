# Issue 010 — 차기 프로젝트 주제 선정 (메타 목적만 승계하는 피벗)

> status: open · created: 2026-08-21
> 전제: Operator 결정 — 새 프로젝트는 **① 메타 목적만 승계**
> (의도공학 사례 연구 + Operator 학습 ↔ 프로젝트 진화 co-evolution).
> ② 거버넌스 헤드라인(H-G1·H-G2)·③ 도메인 A는 승계하지 않음.
> 성격: **연구형(가설 판정)** — yes/no 어느 쪽이든 산출물, 판정 기준 사전 고정 원칙 유지.
> 관심 영역(Operator 선택, 4개 전부): 의도공학 자체 · 사람-AI 학습·인지 · 새 도메인 탐험 · AI 에이전트 행동.

공통 승계 제약(실무): Operator 1명 + 구독 CLI 에이전트(metered API 금지), 저비용(로컬 우선),
사전 고정 판정 + 독립 엔진 심사, negative result = 산출물.

## 후보 A — 의도공학 효과의 통제 실증 (Intent Efficacy Study) ★ 권장

**요약**: "INTENT.md(Why/What/Not) substrate를 가진 에이전트 자율 개발이, 동일 태스크를
spec-only / prompt-only로 수행한 경우 대비 **Not 위반률·방향 이탈(drift)·재작업량**에서
사전 고정 기준으로 우수한가"를 통제 비교로 판정. 심사는 독립 엔진(Codex) — 생성≠심사 원칙 재사용.

- **판정 가설 예시**: H-IE1 "intent-조건 에이전트의 Not 위반률이 통제 조건 대비 유의하게 낮다",
  H-IE2 "의도 진화(Learnings 환류)가 있는 반복 실행이 없는 반복 대비 이탈 누적을 억제한다".
- **Pros**:
  - "의도만 남기고 피벗"의 극한형 — **메타 목적 ①이 그대로 헤드라인 가설로 승격**. 자기정합성 최상.
  - 본 리포의 3회 피벗 이력·Learnings 전량이 **종단 사례 데이터**로 직접 자산화.
  - 관심 영역 4개 중 3개 결합(의도공학 + 에이전트 행동 + Operator 학습이 실험 설계에 내장).
  - 비용 0(로컬 + 구독 CLI). grounded 조사 기준 이 프레이밍의 통제 실증은 희소할 가능성(착수 시 확인).
- **Cons**:
  - 자기참조적 — 실험 설계자·실행자·피험 에이전트가 모두 LLM이라 **오염 통제 설계가 까다로움**
    (조건 간 프롬프트 누출, 태스크 선정 편향).
  - 태스크 세트의 대표성 문제 — 결과가 "이 태스크들에서만"으로 한정될 위험.
  - 효과 크기가 작으면 반복 수를 크게 늘려야 함(구독 사용량 소모).

## 후보 B — 인지 부채 N-of-1 자기실험 (Cognitive Debt Self-Study)

**요약**: "AI 위임 개발에서 Operator의 산출물 이해도는 감쇠하며, 구조화 개입(튜토리얼·quiz·
간격 반복)이 그 감쇠를 유의하게 완화하는가"를 **N-of-1(single-subject, ABAB 교차) 설계**로 판정.
Operator 본인이 피험자, quiz 점수가 지표.

- **Pros**:
  - 사람-AI 학습·인지 축 정면. **Operator 학습이 곧 실험 데이터** — co-evolution의 문자적 구현.
  - 기존 자산(quiz 스킬·experiment-tutorial)이 그대로 측정 도구가 됨.
  - 비용 0, 인프라 없음. N-of-1 방법론은 의학·행동과학에서 확립돼 방법론적 근거 인용 가능.
- **Cons**:
  - N=1 — 일반화 주장 불가(단 "본 Operator에게서 판정"으로 범위 한정하면 정직한 연구).
  - 피험자=실험자라 blinding 불가, 기대 효과(측정 자체가 학습을 유발) 교란.
  - 측정 루틴이 일상 작업에 침투 — 수개월 지속 규율 필요.

## 후보 C — 비전문 도메인 진입 판정 (Novice+Agent Domain Entry)

**요약**: 낯선 전문 도메인 X 하나를 골라 "비전문가 Operator + 에이전트가 **외부 커뮤니티 기준**
(재현 연구 성공, 벤치마크 리더보드 제출, 학회 아티팩트 배지 등)에 도달 가능한가"를 사전 고정
도달 기준으로 판정. 도메인 후보(후속 선택): 생물정보학 재현연구 · 컴파일러 최적화 · 계산화학 ·
암호 구현 검증 등.

- **Pros**:
  - 반도체/EDA 진입에서 검증된 "비전문가+에이전트" 패턴의 재사용 — 새 도메인 학습 = Operator 학습 축 최대.
  - 판정 기준이 **외부에 있어** 자기참조 오염 없음 — 객관성 최상.
- **Cons**:
  - 도메인 선정이 그 자체로 큰 결정(issue 009의 반복) — 착수까지 결정 비용 큼.
  - 외부 기준 의존이라 완주 기간·성공 확률 예측 어려움, 도메인 인프라 비용 발생 가능.
  - 의도공학·인지 축은 부수적으로만 다뤄짐.

## 후보 D — 에이전트 실패 분류학 (Agent Failure Taxonomy)

**요약**: "자율 에이전트 루프의 실패 양상(gaming·drift·위양성·계약 위반)은 안정된 분류 체계로
수렴하며, 분류별 재현 조건을 특정할 수 있는가". 사례 연구 1의 실패 6건+이 시드 코퍼스.

- **Pros**:
  - 기존 프로젝트의 가장 값진 부산물(실패 기록)을 정면 자산화. 커뮤니티 기여 가치 높음.
  - 에이전트 행동 연구 축 정면, 재현 실험은 로컬·저비용.
- **Cons**:
  - ② 거버넌스 층과 주제가 가까워 "메타 목적만 승계"라는 이번 결정과 어긋남 — 사실상 피벗 3.5.
  - 분류학은 판정형(yes/no) 가설로 만들기 어려움 — "수렴" 기준의 사전 고정이 난제.
