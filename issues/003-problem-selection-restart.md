- 사용자: “조사와 해결할 문제 선정부터 다시 진행하고 싶어”.
- 현업 접근 경로: “현재는 없음 — 공개 자료로 조사”.

- 로컬·무료 컴퓨트, 구독 CLI 제약을 조사 가능성 판단에 반영한다.

## 조사 계획 — 검색 전 기준

질문: 공개 자료만으로도 문제의 존재·기존 대안·평가 경로를 확인할 수 있고, 반도체 기업 업무로 이어질 가능성이 있는 구체적인 작업은 무엇인가?

포함: 설계·검증·공정·수율·테스트의 담당 업무, 반복 손실, 공개 이슈·사용자 조사, 원저자 논문·데이터·코드, 공식 제품 기능. 최근 2024–2026 자료를 우선하되 원 데이터·표준·미해결 이슈의 오래된 근거도 포함한다.

제외: 출처 없는 시장 규모, 제3자 재요약만으로 확인한 기술 주장, 기업의 공개 사례를 구매 의사로 바꾸는 추론, 데이터셋 이름만 있고 접근·평가 조건을 확인할 수 없는 성공 주장.

검색: exa MCP만 사용. 업무별 넓은 검색 → 원출처 확인 → 기존 해결책·반대 근거 검색. 기업·공급사 문서, GitHub 원저장소·이슈, 원논문을 구분한다. 학술 DB 3종의 체계적 고찰이 아닌 EXPLORATORY 문제 조사이며 포괄적 문헌고찰로 주장하지 않는다.

선별: 반환된 인용 URL이 없으면 응답 전체 기각·재조회. 자료별 채택·보류·제외 이유와 확인 수준(검색 반환문/추출문)을 남긴다. 홍보 수치는 독립 검증된 성과로 사용하지 않는다.

비교 기준: ① 직접 문제 근거 ② 현행 대안과 남는 작업 ③ 공개 입력·정답·사용 조건 ④ 로컬 검증 비용 ⑤ 결과가 업무 판단에 연결되는 정도. 미확인은 점수로 덮지 않고 미확인으로 남긴다.

선정 관문: 실제 반복 작업을 한 문장으로 설명할 수 있고, 현재 대안과 비교할 방법 및 가장 싼 반증 방법이 있어야 한다. 공개 자료에만 근거한 선정은 검증할 문제의 선정이며 특정 기업 수요의 확정이 아니다.

## 조사 결과

- [재조사 보고서](../literature/problem-selection-2026-09-24.md): 전 분야 후보 P1–P8 비교, 기존 대안, 우선순위와 중단 조건.

- 조사자 권고: **P1 — STDF→ATDF 변환에서 검사 결과의 의미가 어긋나는 문제**를 먼저 검증. 첫 사례는 PRR의 빈 재시험 필드 누락 신고이며, 원 명세·현재 SHA·실행 결과 확인이 다음 관문.
- 수정된 비트 처리 오류(PR #66)는 현재 미해결 문제로 세지 않는다. 현재 도구가 충분하거나 작은 라이브러리 수정으로 해결되면 독립 제품으로 확대하지 않는다.
- 차순위 P2(파형 시간 관계 확인)는 공개 코드 접근·기존 도구와의 차이, P3(공정 예측 신뢰도)는 CMP 파일·사용 조건·시간 식별자를 먼저 확인한다.
- **구현·실험 가설 승인 아님**: 기존 H 가설·LOCKED protocol·판정은 유지한다. P1의 산업 수요와 독립 도구의 추가 가치는 미확인이다.
