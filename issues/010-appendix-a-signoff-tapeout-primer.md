# Issue 010 부록 A — 판정 기준 결정을 위한 학습 브리프: sign-off와 tapeout

> 목적: "칩/RTL 설계를 바이브 코딩으로 수행"하는 차기 프로젝트에서 **완주 판정 기준 3안**
> (실제 tapeout / 로컬 sign-off / PPA 경쟁) 중 하나를 고르기 위해 필요한 배경 지식.
> 대상 독자: 비전문가 Operator. 전문 용어는 처음 나올 때 풀어서 설명한다.

---

## 1. 칩이 만들어지는 길 — RTL에서 실리콘까지

디지털 칩 설계는 대략 다음 단계를 거친다. 사례 연구 1(EDA surrogate)에서 다뤘던
gcd/aes/ibex/jpeg 데이터가 바로 이 파이프라인의 산출물이었다.

```
RTL 작성 → 시뮬레이션 검증 → 합성 → 배치·배선(P&R) → sign-off 검증 → tapeout → 팹 제조 → 실칩
(Verilog)   (동작이 맞는가)  (Yosys) (OpenROAD)        (아래 §2)     (제출)   (수개월)   (수령)
```

- **RTL(Register Transfer Level)**: Verilog 같은 언어로 "클럭마다 데이터가 어느 레지스터에서
  어느 레지스터로 어떻게 이동하는가"를 기술한 설계 원본. 바이브 코딩이 개입하는 주 무대.
- **합성(synthesis)**: RTL을 실제 논리 게이트(AND, OR, 플립플롭)의 그물망(netlist)으로 변환.
- **P&R(Place & Route)**: 게이트들을 칩 면적 위에 배치하고 금속 배선으로 연결. 결과물이
  **GDSII** — 팹(공장)에 보내는 최종 도면 파일.
- **tapeout**: 완성된 GDSII를 팹에 제출하는 행위. 이름은 과거 자기 테이프로 도면을 보내던
  시절의 유산. 제출 후 수개월 뒤 실리콘 칩이 돌아온다.

## 2. sign-off가 뜻하는 것 — "팹에 보내도 되는가"의 3대 검사

sign-off는 "이 도면대로 만들면 물리적으로 동작하는 칩이 나온다"를 도구로 검증하는 관문이다.
핵심 검사 세 가지:

| 검사 | 질문 | 도구 예 (오픈소스) |
|---|---|---|
| **STA (timing)** | 모든 신호가 클럭 주기 안에 도착하는가? (지각하면 오동작) | OpenSTA |
| **DRC (Design Rule Check)** | 도면이 팹의 제조 규칙(선 굵기·간격 최소치)을 지키는가? | Magic, KLayout |
| **LVS (Layout vs Schematic)** | 최종 도면의 회로가 netlist와 동일한가? (배선 실수 검출) | netgen |

- "**clean**"은 이 검사들에서 위반(violation) 0건을 뜻한다. 사례 연구 1의 jpeg 완주 기록에
  나오는 "DRT 다수 iteration 후 violation 0 수렴"이 배선 단계의 이 과정이다.
- 로컬 sign-off 완주 = **돈 안 들이고 여기까지**. 실제 제조는 안 하지만, 업계에서 "설계가
  끝났다"고 부르는 지점까지는 간 것.

## 3. 세 판정 기준의 구조적 차이

연구형(가설 판정) 프로젝트에서 판정 기준은 "성공/실패를 누가 정하는가"의 문제다.

### 3-1. 실제 tapeout 제출 (외부 판정)
- 저비용 공동 셔틀(MPW: 여러 팀이 한 웨이퍼를 나눠 쓰는 방식, 대표적으로 **Tiny Tapeout**)에
  설계를 제출해 실리콘으로 제작.
- **판정의 객관성 최상**: 제출 마감·형식 검사·제조 가능성 판정이 전부 외부에 있다.
  실칩이 동작하면 반박 불가능한 완주 증거.
- 비용: 소액(수만 원~수십만 원대, §4에서 최신가 확인). 기간: 셔틀 일정에 종속(수개월).
- 리스크: 마감 일정이 프로젝트 밖에서 강제됨. 실칩 수령·측정까지 포함하면 판정이 늦어짐
  (단, "제출 승인"까지를 판정점으로 삼으면 완화 가능).

### 3-2. 로컬 sign-off 완주 (내부 판정, 도구가 심판)
- OpenROAD/OpenLane으로 STA·DRC·LVS clean GDSII까지. 비용 0, 일정 자율.
- 판정을 사람이 아닌 **도구가 내리므로** "사전 고정 기준" 원칙과 잘 맞는다. 단 어느 PDK
  (공정 규칙 세트), 어느 클럭 목표로 clean인지가 내부 선택이라 객관성은 tapeout보다 낮다.
- 사례 연구 1 인프라(ORFS flow) 재사용도가 가장 높다.

### 3-3. PPA 경쟁형 (상대 판정)
- **PPA = Performance(속도)·Power(전력)·Area(면적)** — 칩 품질의 3대 지표.
- 같은 스펙의 공개 레퍼런스 설계(예: 동일 ISA의 기존 오픈소스 CPU)와 PPA를 사전 고정 기준으로
  비교 판정. 가설 판정형 연구에 가장 가깝다.
- 난점: "공정한 레퍼런스" 선정이 어렵고(같은 PDK·같은 제약으로 재현해야 비교 가능), 비교
  실험 설계 자체가 큰 작업. 이전 프로젝트 Not("SOTA 성능 주장 금지")과 유사한 함정 —
  성능 경쟁이 목적을 잠식할 위험.

### 조합 가능성
셋은 배타적이지 않다. 예: **로컬 sign-off를 세대별 게이트로 쓰고, 최종 완주 판정만 Tiny
Tapeout 제출로** 거는 2단 구성 — 일상 루프는 비용 0, 최종 판정만 외부.

## 4. 2026년 생태계 현황 (grounded 조사, 2026-08-21 · citation 15+)

### 4-1. Tiny Tapeout — 운영 중, 오히려 확장
- 2026년 셔틀 다수 진행: TTIHP26a/b(IHP SG13G2 공정), TTSKY26a~d(SKY130, ChipFoundry 경유),
  TTGF26a~c(GlobalFoundries 신규). 가까운 마감: **TTIHP26b 2026-09-21**, TTSKY26d 2026-12.
- **가격: 1타일 €70**(약 10만 원). 표준 타일 ≈160×100µm — **디지털 게이트 약 1,000개**
  규모(작은 상태기계·미니 연산기 수준, CPU급은 복수 타일 필요). 제출은 오픈소스
  flow(LibreLane) 기반 GitHub Actions.
- 제출 → 실칩 수령: 제조 6~9개월, 배송 포함 최대 ~1년 (예: TTIHP26b → 2027-06 납품 예정).
- 출처: tinytapeout.com/chips · /faq · /specs/analog · SwissChips(ETH) 공지.

### 4-2. Efabless 폐업(2025-03) 이후
- chipIgnite/OpenMPW 중단. 공백은 **ChipFoundry.io**(ex-Efabless 인력, 프로젝트당 **$14,950**
  — 단독 프로젝트급), wafer.space, Cadence×SkyWater 오픈 MPW, IHP Open PDK 셔틀이 메움.
- **저비용 최저선은 여전히 Tiny Tapeout 타일(€70)** — 개인 연구 규모에서 현실적 유일 경로.

### 4-3. 로컬 sign-off 도구
- **OpenLane 2는 LibreLane으로 개명**(2025-08, FOSSi Foundation 스튜어드십) — 활발 유지,
  Nix 설치 1급 경로. **ORFS**(사례 연구 1에서 쓰던 flow)도 병행 활발. 구 OpenLane v1은 레거시.
- SKY130/IHP에서 합성(Yosys)→P&R(OpenROAD)→DRC(Magic·KLayout)→LVS(Netgen)→STA(OpenSTA)까지
  **로컬 무료 완결 가능** 확인.

### 4-4. LLM/바이브 코딩 RTL 선행 사례 — novelty 지형 (중요)
- **"LLM이 RTL을 써서 실칩이 됐다"는 이미 2023년에 소진**: NYU Chip-Chat(ChatGPT-4 대화만으로
  8-bit 프로세서 → Tiny Tapeout 실리콘, "세계 최초 LLM-설계 칩"), 이후 스파이킹 뉴런
  어레이(TT5)·RSNN(TT6) 등 후속 다수.
- 조사 기준 미개척으로 남은 축: (a) 인간 개입 없는 **자율 에이전트 루프**가
  설계→검증→sign-off→제출을 끝까지 수행, (b) **객관적 게이트/거버넌스가 승격 판정한 설계**의
  tapeout, (c) 다세대 진화 + 통계 검정 기반 후보 선발. 즉 "LLM이 썼다"가 아니라
  "**무인 거버넌스가 판정했다**"가 차별점. (선행 사례와의 대비에서 도출한 분석 — 부재를 직접
  보고한 소스는 없음, 헤지 유지.)
