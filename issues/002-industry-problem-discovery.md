# issue 002: 반도체 기업 전 분야의 문제 발굴

날짜: 2026-09-10 · 상태: 범위 RESOLVED / 구현 대상 OPEN

> 2026-09-24: 사용자 지시로 [공개 근거 재조사](003-problem-selection-restart.md)를 시작했다. 아래 O2→O3→O7은 9월 10일의 조사 제안이며 현재 우선순위는 재조사 보고서를 참조한다.

## 사용자 결정

목표는 엔비디아·삼성전자·SK하이닉스 같은 반도체 기업에 유용한 산출물을 만드는 것입니다. 설계·검증·공정·수율·테스트 전반에서 문제를 찾는 것부터 범위에 포함합니다. 사용자 "진행시켜" 지시에 따라 목표 문서와 1차 문제 탐색을 갱신합니다.

## 반영

- [INTENT.md](../INTENT.md)를 목표의 기준으로 둡니다.
- A/B/C/D는 설계 분야의 선행 탐색으로 유지합니다. 과거 승인·판정·실행 이력은 변경하지 않습니다.
- [비교 보고서](../literature/industry-opportunities.md)에 기업 업무, 현행 대안, 데이터 경로, 검증 지표를 정리합니다.
- 기술 가능성과 산업 효용을 분리하고, 공개 자료만으로 특정 기업의 도입 의사를 단정하지 않습니다.

## 다음 작업 순서 — 조사자 제안

1. 검증 실패 분석 후보 O2: 공개 버그 사례의 로컬 재현 가능성과 기존 디버깅 도구 대비 차이를 확인합니다.
2. 공정 후보 O3: 공개 CMP 데이터 접근·사용 조건을 확인하고, 실제 공정 데이터로 검증할 수 있는 경로를 구체화합니다.
3. 테스트 후보 O7: 사용할 수 있는 STDF 표본과 현행 변환·분석 도구의 문제를 확인합니다.

이는 후속 조사 순서이며, 개발 대상 선정이나 새 실험 protocol LOCK이 아닙니다. 외부 관계자에게 메시지를 보내거나 데이터를 요청한 상태도 아닙니다.

## 후보 선정에 필요한 근거

각 후보에 대해 업무 담당자, 최근 실패 사례, 현행 작업 절차, 측정 가능한 손실, 사용 가능한 입력·정답, 기존 대안의 한계가 필요합니다. 현업 검토를 준비할 때는 이 항목을 한 장으로 정리합니다. 문제가 기존 도구로 충분히 해결되거나 데이터·정답을 확보할 경로가 없으면 해당 후보의 구현은 보류합니다.
