## 튜토리얼 체계 (2026-08-26 도입)

이 프로젝트는 **반도체 비전문가 개발자가 AI와 함께 실험하며 반도체 설계·제조 지식을 학습해 가는 과정**을 포함한다. 각 트랙의 `tutorial.md`가 그 기록이자 교재다.

- **눈높이**: 12살도 이해할 수 있는 서술형 — 전문용어는 등장 즉시 일상 비유로 풀어 설명
- **내용**: 그 트랙이 다루는 반도체 개념 + 우리가 실제로 한 실험 이야기 + 결과가 가르쳐준 것
- **퀴즈**: 각 튜토리얼 끝에 주관식(서술형) 퀴즈 — 정답 베끼기가 불가능한 "왜?"형 질문. 모범 답안은 접힌 섹션(`<details>`)에 분리 — **먼저 스스로 답을 적어본 뒤 펼쳐볼 것**
- **실험 일지**: 각 튜토리얼의 마지막 섹션 — 실험이 진행될 때마다 날짜와 함께 새 배움을 추가

### 튜토리얼 갱신 규칙 (운영 규율)

1. 트랙에 **판정(supported/refuted/inconclusive/무효)** 또는 **주요 마일스톤**(protocol LOCK, 구현 완료, 공개)이 커밋될 때, 같은 작업 흐름에서 해당 트랙 `tutorial.md`의 "실험 일지"를 갱신하고 필요 시 본문·퀴즈를 보강한다.
2. 새 반도체 개념이 실험에 등장하면(예: 새 sign-off 검사, 새 툴) 본문에 눈높이 설명을 추가하고 퀴즈 1문항 이상을 더한다.
3. 튜토리얼 갱신 커밋은 `docs(tutorial):` prefix — 판정 커밋(research(results))과 분리한다.
