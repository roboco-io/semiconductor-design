## 1. 가설 (전사 — 재수정 금지)

**H5**: ICCAD'23 IR drop 공개 리더보드에서 경량 모델(소형 U-Net 또는 tile-tabular GBDT)은 공개 최종 점수표 대비 경쟁력 있는 MAE/F1을 모델 크기·런타임 우위와 함께 달성한다.
**H0**: 경량 모델은 경쟁 구간에 도달하지 못하거나, 도달해도 크기·런타임 우위가 없다.

## 3. 모델 변형·탐색 공간·선택 규칙 (전부 동결)

**전처리 (공통, 동결)**: 입력 3맵은 채널별 z-score 정규화. **CV 단계**: mean/std를 각 fold의 학습 파티션(fake 100 + 해당 fold-train real 8)에서만 계산 — fold-val 입력 불포함(누출 차단). **최종 재학습 단계**: 학습 셋 전체(fake 100 + real 공개 10)에서 재계산해 파일로 커밋(이 통계가 hidden 평가에 사용됨). 타깃(IR drop, V)은 원 단위 유지. V2의 가변 크기 처리: 256×256 타일 분할(stride 256, 경계 zero-pad), 추론 시 타일 재조립(패딩 영역 제외).

**V1 (tile-tabular GBDT, LightGBM 회귀, 동결)** — 피처(픽셀 단위): 로컬 윈도우 통계 = 윈도우 조합 {소={3}, 중={3,5}, 대={3,5,9}} × 3맵 × {mean, max} + 전역 통계(3맵 각 mean·max = 6) + 정규화 좌표 (x/W, y/H). 학습 샘플링: 케이스당 시드 42 균일 무작위 20,000픽셀. LightGBM 기타 파라미터는 라이브러리 기본값 고정. 탐색 그리드: num_leaves {31,63,127} × learning_rate {0.05,0.1} × n_estimators {300,600} × 윈도우 조합 {소,중,대} = 36 구성.
**V2 (소형 U-Net, 파라미터 ≤ 1M 하드캡, 동결)** — 블록: 레벨당 [Conv3×3→BatchNorm→ReLU]×2, 다운=2×2 max-pool, 업=bilinear+skip concat, 출력=1×1 Conv. 손실=L1(MAE). 옵티마이저=Adam(lr 1e-3, β 기본). 배치=타일 8. 사전학습: fake 100으로 30 epoch 고정 → 미세조정: real 공개 fold-train으로 epoch ≤ 60, early stop = fold-val MAE(patience 10). 탐색 그리드: depth {3,4} × base_channels {8,16} = 4 구성(1M 캡 초과 자동 제외).

**최종 재학습 절차 (동결)**: 선택된 구성을 학습 셋 전체로 시드별 재학습. V1 = CV와 동일 하이퍼로 전체 데이터 학습. V2 = fold-val이 없으므로 early stop 대신, 선택 시점 CV 5개 fold에서 관측된 최적 epoch 수의 **중앙값으로 고정 epoch** 학습(사전학습 30 epoch 동일).

**모델 선택 (unblinding 전 완료·커밋)**:
- CV: real 공개 10을 **testcase id 오름차순으로 5-fold(각 2개) 고정 배정** (fold1={tc1,tc2}, fold2={tc3,tc4}, fold3={tc5,tc6}, fold4={tc11,tc12}, fold5={tc17,tc18}).
- 선택 규칙 (판정 기준과 정렬된 결정적 3단계): ① fold 평균 MAE ≤ 3.649e-4 **이고** fold 평균 F1 ≥ 0.2589 를 모두 충족하는 구성 중 MAE 최소 ② ①이 없으면 F1 ≥ 0.2589 충족 구성 중 MAE 최소 ③ ②도 없으면 fold 평균 F1 최대 구성. tie-breaker(동률 시): ⓐ 직렬화 크기 작은 쪽 ⓑ 그래도 동률이면 **구성 ID 문자열 사전순 최솟값** — 구성 ID = `V{1|2}:key=value` 쌍을 키 사전순으로 연결한 문자열(전수 결정성 보장).
- 탐색 예산: 변형별 위 그리드 전수(36+4) 이내, 추가 구성 금지. 탐색·선택의 학습 시드 = 42 고정.
- 최종 제출 모델 1개(변형×구성)를 hidden 평가 **전에** 선택해 커밋으로 기록.

**판정용 시드·집계**: 선택된 구성을 시드 42/43/44로 3회 학습 → 각 시드로 hidden 10 평가 → **성능 판정값 = 시드별 (hidden 10 평균 MAE, 평균 F1)의 3-시드 산술 평균**(표준편차 병기). **경량성 판정값(크기·추론 시간) = 3개 시드 모델 측정값의 최댓값**(보수적·결정적). **최종 학습 실패 처리**: 시드별 최종 학습이 실패(상한 초과 포함)하면 성공한 시드들로 판정하되 **최소 2개 시드 필요** — 성공 시드가 2개 미만이면 실험 무효(§8 터미널 ⓐ에 준함).

## 7. 채점기 (생성≠심사·사전 검증)

- 지표 정의는 콘테스트 공식 문서(contest-description.pdf): MAE(V), hotspot F1(핫스팟 = 해당 케이스 정답 최대값의 90% 초과 픽셀).
- 자체 구현 채점기를 **unblinding 전에** fake·real 공개 데이터에서 Alpha-Chip 공개 채점 구현과 교차 검증: 허용 오차 = MAE 상대 차 ≤ 1e-6, F1 완전 일치. 불일치 시 unblinding 금지, 공개 데이터에서 원인 규명·수정 후 재검증. **수정 불능이면 실험 무효**(판정 자체를 내리지 않음). 정본(canonical)은 콘테스트 문서 명세이며, 자체 구현이 명세를 따르는지가 판단 기준.
- unblinding 이후 채점기 변경 금지.

## 8. 예산·비상 축소 (객관 트리거)

- 총 컴퓨트 예산: 실행 개시 커밋부터 7일, 학습·평가 CPU 시간 상한 60시간 — **회계 분할: 탐색(CV) 32시간 / 예약분 28시간**. 예약분 내역(산술 검증): 최종 3-시드 학습 최악 3×8h(V2)=24h + hidden 평가·채점기 교차검증·비교자 측정 합산 상한 4h = 28h ✓ (V1 선택 시 3×0.5h=1.5h로 여유). 예약분은 탐색이 침범 불가.
- 구성당 상한: V1 30분 / V2 4시간(사전학습 포함 시 8시간). 초과 구성은 실패 처리(재시도 없음).
- **실행 순서 고정 (탐색)**: V1 그리드를 (num_leaves 오름차순 → learning_rate 오름차순 → n_estimators 오름차순 → 윈도우 소<중<대) 사전식 순서로 전부 → 이어서 V2를 (depth 오름차순 → base_channels 오름차순) 순서로. 이 순서 외 실행 금지 — 비상 축소 시점의 "완료 구성 집합"이 순서에 의해 결정적이 되도록.
- **비상 축소 트리거(객관식, 탐색 32h 기준)**: 잔여 소요 추정치가 탐색 잔여 예산을 초과하는 시점에 발동. 추정치 = Σ(변형별: 완료 구성 실측 평균 × 잔여 구성 수) — **완료 구성이 0인 변형은 구성당 상한(V1 30분, V2 8h)을 추정치로 사용**(zero-history 규칙). 축소 순서 고정: ① V1 n_estimators {600} 제거 ② V2 사전학습 fake 100→50 (시드 42 균일 무작위, 목록 커밋; 추정치에는 V2 상한을 8h→4h로 반영) ③ V1 윈도우 {대} 제거 ④ V2 base_channels {16} 제거 — **적용 시점에 해당 항목이 미실행 구성에 영향을 주지 않으면(no-op) 즉시 다음 순서 항목을 적용**. 완료 구성 결과는 유지·선택 후보에 남고, 축소는 미실행 구성에만 적용. 이 순서 외 축소 금지.
- **트리거 평가 시점·터미널 규칙**: 트리거는 **각 구성 완료 직후에만** 평가(실행 전 선제 발동 없음 — 첫 평가는 1번째 구성 완료 후). ①-④를 모두 소진해도 추정치가 초과하면: 잔여 구성을 고정 실행 순서대로 계속 실행하되 **탐색 실측 누계가 32h에 도달하는 순간 탐색을 즉시 종료**하고, 그 시점까지의 완료 구성만으로 §3 선택 규칙을 적용한다(유효 완료 0이면 터미널 ⓐ). 산술 검증: 최악 경로에서도 예약분 28h는 불침범 — 탐색은 실측 32h에서 강제 종료되므로 총 60h 상한 유지 ✓.
- **터미널 결과 (전수 포괄 보강)**: ⓐ 유효 완료 구성이 0(전 구성 학습 실패 → 선택 불능) → **실험 무효**(판정 없음, negative 기록) ⓑ 예약 예산 소진·기한 초과로 hidden 평가 미도달 → **실험 무효** ⓒ 채점기 교차검증 수정 불능(§7) → **실험 무효**. 무효는 refuted가 아니며 사유와 함께 research-log에 기록 후 Reflection으로 이동.
