# 트랙 D 계획서 — IR drop 경량 예측 모델

가설: H5 · 근거: [raw/02](../literature/raw/02-ml-model-opportunities.md) (ICCAD'23 Contest Problem C — 채점에 모델 크기·런타임 포함, 공개 점수표 존재)

## 목표

정적 IR drop 맵 예측에서 **경량 모델**(tile-tabular GBDT 및 소형 U-Net 두 변형)로 ICCAD'23 공개 벤치마크의 공개 점수표 대비 경쟁력 있는 MAE/F1을 **모델 크기·추론 런타임 우위**와 함께 달성한다. 유일하게 "작음"이 채점에 유리한 공개 리더보드라 소형 모델의 가치를 객관 입증하기 가장 좋은 무대. 포트폴리오에서 순수 "모델" 트랙 대표 (도구 3 + 모델 1 균형).

## 왜 D가 H4(검증 관리 도구) 대신인가

- H4는 신생 경쟁(xevdb·TraceWeave) 진행 중 + UCIS 학습 비용 — 차별 우위 불확실
- D는 공개 데이터·공개 점수표·고정 스플릿으로 **판정이 가장 객관적**, INFRA-0(EDA 환경)와 독립이라 즉시 착수 가능 — 병렬성 극대화
- A의 QoR 예측기(H1.1)와 ML 파이프라인 기술이 공유됨 (피처 엔지니어링·평가 규율)

## MVP 스코프

- 데이터: ICCAD'23 Problem C (ASU-VDA-Lab 공개 repo: 실회로 + hidden 평가 스플릿 정의) + BeGAN 합성 데이터 사전학습
- 모델 변형 2종 (사전 고정): ① tile 단위 피처(전류밀도·저항 경로·PDN 밀도) GBDT ② 파라미터 수 제한 소형 U-Net
- 평가: 공식 스플릿 MAE·hotspot F1 + 추론 시간·파라미터 수 병기, 공개 최종 점수표와 동일 형식 비교

비스코프: 동적 IR drop, 상용 툴 통합, 대형 모델 변형(GPU 필요 영역).

## 유용성 판정 기준 (protocol LOCK 항목 — 초안)

| 축 | 기준(초안) | 방법 |
|---|---|---|
| 벤치마크 성능 (필수) | 공식 스플릿에서 공개 점수표의 사전 고정 순위 구간 내 MAE/F1 | 콘테스트 공식 평가 스크립트 재사용 |
| 경량성 | 점수표 상위권 대비 파라미터 수·추론 시간 우위 (배수로 사전 고정) | 동일 하드웨어 측정 |
| 재현성 | 코드+가중치+환경 공개, 원클릭 재현 | 재현 스크립트 + CI |

주의: 판정 스플릿은 개발 중 접근 금지(홀드아웃 규율). 하이퍼파라미터 탐색은 학습 데이터 내 교차검증만.

## 태스크 그래프

```
D1 ─→ D1.5(스플릿·판정 기준 protocol LOCK) ─→ D2 ─→ D3 ─→ [H5 판정] ─→ D4
(INFRA-0와 독립 — 즉시 착수 가능)
```

| ID | 태스크 | 산출물 | 의존 |
|---|---|---|---|
| D1 | 데이터 파이프라인: 다운로드·전처리·피처 추출 + 공식 평가 스크립트 통합 | 데이터 모듈 + 평가 하네스 | 없음 |
| D1.5 | protocol LOCK: 스플릿·지표·순위 기준·모델 변형 2종 고정 (Codex 게이트) | LOCKED protocol | D1 |
| D2 | 모델 2변형 구현·학습 (BeGAN 사전학습 → 실회로 미세조정) | 모델 + 학습 로그 | D1.5 |
| D3 | 공식 스플릿 평가 → 점수표 비교 리포트 → H5 판정 | 평가 리포트 | D2 |
| D4 | 공개(코드+가중치) + 리포트 공유, JOSS/워크숍 제출 검토 | public repo | D3 |

## 리스크

- **콘테스트 데이터 접근성**: repo 접근·라이선스를 D1에서 최우선 확인 — 불가 시 CircuitNet IR 서브셋으로 대상 변경(protocol 재작성, EXPLORATORY 아님 — LOCK 전 변경은 허용).
- **hidden 스플릿 부재 가능성**: 공개본에 hidden 회로가 없으면 공개 회로의 leave-one-out으로 대체하고 점수표 비교는 참고치로 강등 — D1.5에서 확정.
- **순수 성능 경쟁의 한계**: novelty가 "경량화 각도"에 한정됨을 인지 — 판정 기준에 경량성 축을 명시해 주장 범위를 정직하게 유지.
