# Field Survey: 반도체 설계에 유용한 SW/모델 — 무엇을 만들 것인가 (2024-2026)

날짜: 2026-08-25 · 도구: exa MCP (병렬 조사 에이전트 5기, 검색 31회, citation 기각 0건) · 원본: `literature/raw/01`-`05`

## 1. Review Protocol (사전 고정)

- **질문**: "반도체 설계 현장에 실제 유용한 소프트웨어/모델 중, 1인 개발자가 바이브 코딩으로 만들 수 있는 것은 무엇인가"
- **선정 기준**: ① 수요 근거(이슈·포럼·설문의 실제 호소) ② 유용성의 객관 검증 가능성 ③ 1인+AI·로컬 컴퓨트·오픈소스 실행성 ④ 선점/경쟁 리스크
- **조사 축**: 도구 공백·수요(①) / 소형 ML 모델 기회(②) / 검증·디버깅 공백(③) / 워크플로우·실험 관리(④) / 바이브 코딩 선례·검증 경로(⑤)

## 2. 핵심 발견

### F1. 플로우는 성숙, "해석·관리 계층"이 공백 (①③④ 수렴)
오픈소스 EDA는 엔진(OpenROAD/LibreLane/Verilator/cocotb)까지는 성숙했으나 그 위의 계층이 비어 있다:
- **해석**: 타이밍 리포트 읽기 어려움(OR #1759, mcp#96 "Impact: High"), 암호 같은 실패 로그(OpenLane #1183 "거의 모두가 겪음")
- **검증 관리**: 커버리지 merge/시각화 부재(cocotb 설문 최다 불만), 회귀 실패 triage 수작업, sby 반례 재실행 불가(sby #300)
- **실험 관리**: METRICS2.1 포맷은 있는데 run 추적·비교 도구가 없음 — "하드웨어판 MLflow" 부재 (HBS 전수 비교로 확인)

### F2. 소형 ML 모델은 "무주공산 + CPU 가능" 조합이 존재 (②)
- 공개 데이터셋 성숙: CircuitNet(BSD-3), EDA-Schema(7,800+ 인스턴스, 완전 재현 가능), Metrics4ML, ICCAD'23 IR drop 콘테스트(모델 크기·런타임이 채점 기준 — 소형 모델에 유리한 공개 리더보드)
- **tabular QoR 조기 예측은 사실상 무주공산**: 표준 스플릿·리더보드 없음, GBDT 공개 구현 희소, 상용(DSO.ai·Cerebrus)이 파는 가치("예측으로 반복 감소")의 오픈소스 공백
- 2025년 XGBoost가 CNN을 이긴 선례(R² +0.12, 추론 14.95배) — 소형 모델 경쟁력 실증

### F3. 바이브 코딩 방법론은 이미 실증 단계 (⑤)
- Normal Computing: 1인+AI 43일에 580K줄 Verilog 시뮬레이터·형식검증 스택 — 품질 담보는 라인 리뷰가 아니라 **기계적 게이트**(외부 벤치마크, mutation testing, BMC/LEC)
- Meta CoreSmith·Huawei RTLScout·NVIDIA ACE-RTL — 검증 게이트 기반 에이전틱 EDA 개발이 2026년 산업 표준 패턴화
- 자기 소유 repo의 에이전트 주도 개발은 정책 충돌 없음 (업스트림 기여 시 라벨링 필요)

### F4. "유용성"의 객관 검증 경로가 명확히 존재 (⑤)
- 최강 증거 = 외부 공인 벤치마크 + 재현 아티팩트 > 채택 증거(타 그룹 사용) > 시간 절감 전/후 표(DVCon 표준) > 스타/다운로드(proxy)
- 학술 진입로: WOSET(오픈소스 EDA 도구 논문, repo 필수) / JOSS(도구 피어리뷰, CI·impact 증거 요구) / ICCAD tool paper
- 성공/실패 교훈: Surfer(기존 포맷 + 나은 UX + 임베드 가능 = 성공) vs WAL(새 언어 강요 = 채택 실패)

## 4. 시사점

수요 근거·검증 경로·실행성을 모두 갖춘 후보가 9개 확보됐다. 구조적으로 주목할 조합: **C1(실험 추적 도구) → C4(QoR 예측 모델)**은 "소프트웨어"와 "모델"을 하나의 로드맵으로 잇는다 — C1이 수집하는 METRICS2.1 데이터가 C4의 학습 데이터가 되고, C4의 예측기가 C1 대시보드의 기능이 된다. 유용성 검증도 단계적(먼저 도구 채택, 다음 예측 정확도·시간 절감).
